🔄 Decimal to Binary Conversion

decimal-to-binary 
// 25 लाई Binary मा convert गर्ने (2 ले भाग गर्दै)
25 ÷ 2 = 12  remainder 1   ← LSB (सबभन्दा तल्लो bit)
12 ÷ 2 = 6   remainder 0
6  ÷ 2 = 3   remainder 0
3  ÷ 2 = 1   remainder 1
1  ÷ 2 = 0   remainder 1   ← MSB (सबभन्दा माथिल्लो bit)

// तल्लोबाट माथि पढ्ने: (25)₁₀ = (11001)₂
🔴 Exam Trick Remainder तल्लोबाट माथि पढ्नुपर्छ! LSB पहिले, MSB अन्तमा। यो उल्टो नगर्नु।

➡️ Binary to Decimal Conversion

binary-to-decimal 
// (1101)₂ लाई Decimal मा convert गर्ने

= 8    + 4    + 0    + 1
= 13

// (1101)₂ = (13)₁₀

📝 ASCII Code

  • ASCII = American Standard Code for Information Interchange
  • 7-bit code → 128 characters represent गर्न सक्छ (0–127)
  • 'A' = 65, 'a' = 97, '0' = 48
  • Uppercase र lowercase को फरक = 32
💡 याद गर्नु 'A'(65) + 32 = 'a'(97) | '0' = 48, '9' = 57 | Space = 32 | Enter = 13

⚙️ Universal Gates बाट अरू Gates बनाउने

NAND implementation
// NAND बाट NOT बनाउने
NOT(A) = NAND(A, A)

// NAND बाट AND बनाउने
AND(A,B) = NOT[NAND(A,B)] = NAND[NAND(A,B), NAND(A,B)]

// NAND बाट OR बनाउने
OR(A,B) = NAND[NAND(A,A), NAND(B,B)]

// NOR बाट NOT बनाउने
NOT(A) = NOR(A, A)

Boolean Algebra

Logic expressions simplify गर्न प्रयोग हुने mathematical rules।

📐 Boolean Laws

LawAND FormOR Form
IdentityA · 1 = AA + 0 = A
Null/DominanceA · 0 = 0A + 1 = 1
IdempotentA · A = AA + A = A
ComplementA · Ā = 0A + Ā = 1
Double ComplementĀ̄ = A
CommutativeA·B = B·AA+B = B+A
Associative(A·B)·C = A·(B·C)(A+B)+C = A+(B+C)
DistributiveA·(B+C) = A·B+A·CA+(B·C) = (A+B)·(A+C)

🔁 De Morgan's Theorem

De Morgan's Laws
// First Theorem: NAND → NOT of AND
̄(A·B) = Ā + B̄
NOT(AND) = OR of NOTs

// Second Theorem: NOR → NOT of OR
̄(A+B) = Ā · B̄
NOT(OR) = AND of NOTs

// Example: Simplify ̄(A·B) + ̄(A+C)
= (Ā+B̄) + (Ā·C̄)
= Ā + B̄ + Ā·C̄
= Ā(1+C̄) + B̄
= Ā + B̄
🔴 Exam Must Know De Morgan's: bar तोड्दा AND↔OR हुन्छ र हरेक variable complement हुन्छ।

✏️ SOP र POS Forms

  • SOP (Sum of Products): Minterm — 1 हुने rows AND गरेर OR गर्ने
  • POS (Product of Sums): Maxterm — 0 हुने rows OR गरेर AND गर्ने
SOP example
// F = Σm(1,3,5,7) — output 1 हुने minterms
m₁ = ĀBC̄... wait, 3 variables A,B,C:
m₁(001) = Ā·B̄·C
m₃(011) = Ā·B·C
m₅(101) = A·B̄·C
m₇(111) = A·B·C

F = Ā·B̄·C + Ā·B·C + A·B̄·C + A·B·C
  = C(Ā·B̄ + Ā·B + A·B̄ + A·B)
  = C·1 = C   ← Simplified!
Chapter 05

Karnaugh Map (K-Map)

Boolean expressions graphically simplify गर्ने method। Exam मा सबैभन्दा बढी आउने topic!

🗺️ K-Map Rules

  • Groups: 1, 2, 4, 8, 16 — power of 2 मात्र
  • जति ठूलो group, उति simple expression
  • Groups overlap हुन सक्छन् — एउटा 1 धेरैपटक प्रयोग हुन सक्छ
  • Map wrap-around हुन्छ (edges र corners जोडिन्छन्)
  • Don't care (X/d) लाई 1 वा 0 जे convenient होस् treat गर्नु
🔴 Grey Code Order याद गर्नु! 2-variable: 00, 01, 11, 10 (NOT 00, 01, 10, 11) — यो Gray Code order हो।

📐 2-Variable K-Map

2-variable K-Map
         B=0   B=1
A=0  |  m₀  |  m₁  |
A=1  |  m₂  |  m₃  |

// F = Σm(0,1,3) को K-Map:
         B=0   B=1
A=0  |   1  |   1  |
A=1  |   0  |   1  |

Group 1: m₀,m₁ → Ā     (top row, B cancel)
Group 2: m₁,m₃ → B      (right column, A cancel)
F = Ā + B

📐 3-Variable K-Map Layout

3-variable K-Map
        AB=00  AB=01  AB=11  AB=10
C=0  |  m₀  |  m₂  |  m₆  |  m₄  |
C=1  |  m₁  |  m₃  |  m₇  |  m₅  |

// Grouping rules:
// Pair (2 cells)   → 1 variable eliminate
// Quad (4 cells)   → 2 variables eliminate
// Octet (8 cells)  → 3 variables eliminate
💡 Exam Tip K-Map मा AB=00, 01, 11, 10 order — 10, 11 को order बिर्सनु भएन! यो Gray Code हो।
Chapter 06

Combinational Circuits

Output केवल current inputs मा निर्भर — memory हुँदैन। Half Adder, Full Adder, Multiplexer, Decoder।

➕ Half Adder

ABSum (S)Carry (C)
0000
0110
1010
1101
Half Adder equations
Sum   = A XOR B  = A⊕B
Carry = A AND B  = A·B

// Limitation: Carry in लिन सक्दैन!

➕ Full Adder

3 inputs: A, B, Cin (previous carry). 2 outputs: Sum, Cout

Full Adder equations
Sum  = A ⊕ B ⊕ Cin
Cout = A·B + B·Cin + A·Cin
     = A·B + Cin·(A⊕B)

// Full Adder = 2 Half Adders + 1 OR Gate
// Multi-bit addition मा Full Adder chain गरिन्छ
🔴 Exam Important Half Adder: 2 inputs (no carry-in) | Full Adder: 3 inputs (with carry-in) | यो फरक बिर्सनु भएन!

🔀 Multiplexer (MUX)

  • Many-to-one: 2ⁿ inputs → 1 output, n selection lines
  • 4:1 MUX = 4 data inputs, 2 select lines, 1 output
  • 8:1 MUX = 8 data inputs, 3 select lines
  • MUX लाई "Data Selector" पनि भनिन्छ
💡 MUX as Universal Circuit MUX बाट जुनसुकै Boolean function implement गर्न सकिन्छ।

🔢 Decoder र Encoder

  • Decoder: n inputs → 2ⁿ outputs। 3:8 decoder = 3 inputs, 8 outputs
  • Encoder: 2ⁿ inputs → n outputs (Decoder को उल्टो)
  • Priority Encoder: Multiple inputs active भए highest priority लाई encode गर्छ
  • BCD to 7-segment decoder — display मा digit देखाउन
Chapter 07

Sequential Circuits

Output = current inputs + previous state (memory हुन्छ)। Clock signal मा निर्भर।

⚖️ Combinational vs Sequential

FeatureCombinationalSequential
Memoryछैनछ (state)
Output depends onCurrent input onlyInput + Past state
Clockआवश्यक छैनआवश्यक
ExamplesAdder, MUX, DecoderFlip-Flop, Counter, Register
Feedbackछैनछ

🕐 Synchronous vs Asynchronous

  • Synchronous: Clock edge मा trigger हुन्छ — predictable, common
  • Asynchronous: Input change हुनासाथ trigger — faster तर design गाह्रो
  • Positive edge triggered: clock 0→1 जाँदा
  • Negative edge triggered: clock 1→0 जाँदा
💡 Latch vs Flip-Flop Latch = Level triggered (clock level 1 हुँदासम्म) | Flip-Flop = Edge triggered (clock edge मा मात्र)

Flip-Flops

Digital memory को basic unit — SR, D, JK, T flip-flops।

🔷 SR Flip-Flop

SRQ(next)Condition
00QNo change
010Reset
101Set
11?Invalid (forbidden!)
🔴 SR FF को Problem S=1, R=1 = Invalid state — यो forbidden state हो। यही problem solve गर्न JK FF आयो।

🔶 JK Flip-Flop

JKQ(next)Operation
00QNo change
010Reset
101Set
11Q̄Toggle ← SR को problem solve!
💡 JK = Most Versatile FF J=K=1 → Toggle (Q complement हुन्छ) — SR को invalid state problem सोल्व! JK सबैभन्दा popular FF हो।

🔸 D Flip-Flop र T Flip-Flop

DQ(next)T FFQ(next)
00T=0No changeQ
11T=1ToggleQ̄
  • D FF: Data/Delay — Q(next) = D। Data store गर्न प्रयोग। SR को S=D, R=D̄
  • T FF: Toggle — T=1 भएमा state toggle हुन्छ। Counter design मा प्रयोग। JK को J=K=T

🔄 FF Conversion याद गर्ने

Convert toMethod
JK → DJ=D, K=D̄
JK → TJ=T, K=T
JK → SRJ=S, K=R (invalid state remain)
D → TD = T⊕Q
D → SRD = S + R̄Q
Chapter 09

Registers & Counters

Flip-flops को combination — data store र count गर्न।

📋 Shift Registers

  • SISO: Serial In Serial Out — एक-एक bit in, एक-एक bit out
  • SIPO: Serial In Parallel Out — एक-एक bit in, सबै एकैपटक out
  • PISO: Parallel In Serial Out — सबै एकैपटक in, एक-एक bit out
  • PIPO: Parallel In Parallel Out — सबै एकैपटक in र out
💡 Application Shift Register: data transmission, serial-to-parallel conversion, delay element, ring counter।

🧠 RAM Types

  • SRAM (Static RAM): Flip-flops बाट बनेको। Fast, expensive, cache मा प्रयोग

💡 SRAM vs DRAM SRAM = Fast, Expensive, No refresh needed, Cache | DRAM = Slow, Cheap, Refresh needed, Main RAM

📐 Memory Capacity Calculation

memory-calc
// Memory size = 2^(address lines) × data width

// Example: 12 address lines, 8 data lines
Locations = 2¹² = 4096 = 4K locations
Data width = 8 bits = 1 byte
Total = 4K × 8 bits = 4KB

// 1KB = 1024 bytes = 2¹⁰
// 1MB = 1024 KB   = 2²⁰
// 1GB = 1024 MB   = 2³⁰
🔴 Exam Formula Address lines = n → 2ⁿ memory locations। 16 address lines = 64K locations।
